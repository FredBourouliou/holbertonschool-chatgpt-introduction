# Debugging Projects

This folder contains several Python programs that demonstrate different programming concepts and error handling techniques.

## Programs

### 1. Factorial Calculator (`factorial.py` & `factorial_recursive.py`)
Two implementations of a factorial calculator:
- `factorial.py`: Iterative implementation
- `factorial_recursive.py`: Recursive implementation

**Usage:**
```bash
python3 factorial.py <number>
python3 factorial_recursive.py <number>
```

### 2. Checkbook Manager (`checkbook.py`)
A simple checkbook management program that allows users to:
- Deposit money
- Withdraw money
- Check balance
- Exit the program

**Features:**
- Input validation for amounts
- Error handling for non-numeric inputs
- Protection against negative amounts
- User-friendly interface

**Usage:**
```bash
python3 checkbook.py
```

### 3. Tic-tac-toe Game (`tic.py`)
A command-line implementation of the classic Tic-tac-toe game.

**Features:**
- Two-player gameplay (X and O)
- Input validation
- Error handling
- Draw detection
- Win detection (rows, columns, diagonals)
- Option to play again

**Usage:**
```bash
python3 tic.py
```

## Error Handling
All programs include robust error handling for:
- Invalid inputs
- Out-of-range values
- Type mismatches
- Edge cases

## Requirements
- Python 3.x
- No additional packages required
