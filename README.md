# ChatGPT Introduction Project

This repository contains a collection of programming exercises and projects that demonstrate various programming concepts, debugging techniques, and practical applications. Each folder focuses on different aspects of programming and problem-solving.

## Project Structure

### 1. Debugging (`/debugging`)
A collection of Python programs focusing on error handling and debugging techniques:
- Factorial calculators (iterative and recursive implementations)
- Checkbook management system
- Tic-tac-toe game

[View Debugging Projects →](./debugging/README.md)

## Learning Objectives
- Understand and implement proper error handling
- Practice debugging techniques
- Create user-friendly command-line interfaces
- Implement various programming algorithms
- Write clean, maintainable code
- Document code properly

## Skills Demonstrated
- Python programming
- Error handling and input validation
- Algorithm implementation
- Game development
- Financial calculations

- Markdown for documentation

## Installation
1. Clone the repository:
```bash
git clone https://github.com/yourusername/holbertonschool-chatgpt-introduction.git
```

2. Navigate to the project directory:
```bash
cd holbertonschool-chatgpt-introduction
```

3. Run any program from its respective directory:
```bash
cd debugging
python3 program_name.py
```

## Requirements
- Python 3.x installed on your system
- Basic understanding of command-line operations
- Git (for cloning the repository)
